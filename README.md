# SMS Frontend (Web)

This repository contains the **web frontend** for the School Management System.
.
.

## Mobile app

The Expo mobile app has been moved out of this repository so Vercel only builds/deploys the web app.

- **Mobile repo**: `git@github.com:shagun1911/SMS-MOBILE.git`

## Getting started

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

## Deploy (Vercel)

Deploy the repository root (this web app). The former `mobile/` folder is no longer part of this repo.
