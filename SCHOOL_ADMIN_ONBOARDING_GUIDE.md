# School Management System - Non-Technical Onboarding Guide

## Who this guide is for

This guide is for school owners, principals, office staff, and operators who are **not technical**.

It explains:
- What to do first after a school is created by Master Admin
- What must be done in order
- What can be done later anytime
- Common dependency rules (what blocks what)

---

## 1) First, how a school is created

### Master Admin action
Master Admin creates a new school from the Master panel.

After this, School Admin logs in and starts initial setup.

---

## 2) Mandatory setup order (Day 1 / Initial Setup)

Follow this order to avoid errors.

### Step 1 - Complete school branding and identity (Settings)
Go to **Settings** and upload:
- School Logo
- School Stamp
- Principal Signature

Why: these are used in official outputs like receipts, IDs, and documents.

---

### Step 2 - Create Session
Create academic session (for example yearly or 6-month as needed).

Examples:
- 2026-2027 (yearly)
- 2026-H1 / 2026-H2 (half-year style workflow)

Important:
- Without an active session, key academic operations are blocked.

---

### Step 3 - Create Classes and Sections
Create all required class/section combinations.

Examples:
- Class 1 - A
- Class 1 - B
- Class 2 - A

Important:
- Classes/sections are required before assigning students.

---

### Step 4 - Define Fee Structure (Class-wise)
Set fee structure for each class you created.

Important:
- If a class has no fee structure, student admission in that class is blocked.

---

### Step 5 - Add Staff
Add teachers and other staff members.

Examples:
- Teachers
- Accountant
- Transport staff

---

### Step 6 - Add Students
Now add students into classes/sections with fee setup.

Important:
- Student addition depends on:
  - Active session
  - Existing class/section
  - Fee structure for that class

---

### Step 7 - Configure Transport (Bus Routes)
In **Transport**, define:
- Bus route details
- Driver details
- Conductor details

Important:
- Without complete route + driver + conductor details, students cannot be assigned to that bus.

---

## 3) Dependency rules (very important)

Use these rules as quick checks:

- **No Session -> cannot proceed with class/student/teacher academic flow**
- **No Class/Section -> cannot place students**
- **No Fee Structure for a class -> cannot add student in that class**
- **No route/driver/conductor -> cannot assign student to bus**

---

## 4) What can be done later anytime

After initial setup, school can continue regular operations:

- Add more students
- Add more staff
- Add new classes/sections
- Add/adjust fee structures
- Add/modify bus routes
- Create exams
- Edit timetable
- Promote students (Promotion tab)
- Generate Admit Cards
- Generate Student ID Cards
- Generate Report Cards / Results

---

## 5) Suggested practical rollout plan

### Day 1
- Steps 1 to 4 (Branding, Session, Classes, Fee Structure)

### Day 2
- Step 5 and Step 6 (Staff, Students)

### Day 3
- Step 7 (Transport) and first exam/timetable setup

---

## 6) Simple checklist (print/share)

- [ ] School created by Master Admin  
- [ ] Logo, Stamp, Principal Signature uploaded  
- [ ] Session created and active  
- [ ] Classes and Sections created  
- [ ] Fee Structure configured for each class  
- [ ] Staff added  
- [ ] Students added  
- [ ] Transport routes + driver + conductor configured  
- [ ] Students assigned to buses (if transport used)  

---

## 7) Notes for operators

- Do setup in order to avoid blocked actions.
- If something is not working, check dependencies first (session, class, fee setup, transport details).
- Keep branding and signature updated for clean official documents.
